# Drupal Editor Manual Rules

- Follow the editor-manual skill and project profile for editions, content
  location, screenshot manifests, capture targets, and export commands.
- Document only features, labels, permissions, and behavior verified in the
  actual site/configuration. Do not present planned or unverified behavior as
  available.
- Match interface labels and language conventions. Use semantic headings,
  clear task steps, accessible links/images, and a logical document structure.
- Capture only approved environments/accounts. Mask personal or sensitive
  information and verify every screenshot for accuracy and usefulness.
- Do not change site content/configuration to enable a capture. Review exported
  artifacts and report workflows that could not be verified.
